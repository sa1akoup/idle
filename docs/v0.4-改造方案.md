# V0.4 详细改造方案

> 对应产品方向：`搜打撤放置游戏V0.4更新方向.md`  
> 日期：2026-09-04  
> 本版只做：黑市商人、第二张图（含 Boss）  
> 引擎：默认仍 `exploration-engine-v18`；仅当按图分叉结算规则时再升 v19

## 1. 范围

| 阶段 | 交付 | 不交付 |
|---|---|---|
| A | 黑市开放、跨类收购、低档目录、存量解锁 | Scav 身份、保险 |
| B | `factory_woods` 地图、容器/事件、探索页选图、合同延伸 | 第三张图 |
| C | 新图 Boss 遭遇 + `BossLootItems` 掉落 | 城区刷 Boss、档案 |

不做：Scav 行动、藏身处生产、比特币、射击场、联合商人、终局档案。

## 2. 现状锚点

- 黑市：`merchant_defs.id=black`，`Open=false`；出售两处校验 `item.MerchantCategory == merchant.Category`（实例货与堆叠货），跨类卖不掉。
- 收购价：`sellMultiplier` 约 30%～45% 标价（随好感）。
- 货架：`MerchantCatalog` 走 `ListByMerchantCategory(merchant.Category)`。黑市类目物品很少，直接按 category 滤会空架。
- 存量适配：`currentUserDataUpgradeVersion=4`，机械商人解锁是 `progressionBootstrapVersion=5`。黑市解锁另开 v6，不重跑 v4/v5。
- Boss：`template_boss_killa`（室内）、`template_boss_shturman`（室外远距）已在种子里；`enemygen` 已吃 `BossWeaponID/ArmorID/Name`。
- 城区节点全是 patrol/guard/elite，遭遇池无 boss。`BossLootItems` 模型有，击杀掉落未接；`engine.Enemy` 也还没有该字段。
- 快照构建已 `Where("map_id = ?", mapID)` 拉遭遇池，新图 boss 池不会漏进城区局。
- 地图 API 已按 `maps/:id/graph` 拉图；探索页下拉已 `v-for="item in maps"`。缺的是第二份种子，不是新出发接口。
- `seedEvents` 会 **全表删除** 事件绑定和遭遇池再插入。新图的池必须写进 `encounterPools()`，不能另起一套只插一次的旁路。
- `nodeRisk` 没有 `boss` 分支，会落到 default=1（比巡逻还安全）。新图挂 Boss 前必须补风险，否则均衡/潜行路线会主动钻办公室。

## 3. A：黑市 LL1

### 3.1 Seed 与存量

- `seed_merchants`：`black.Open = true`，文案改为销赃/杂物（去掉「待开放」）。
- 新 `user_data_migrations` 版本 v6：对已有用户 `unlockMerchantIfOpenTx(..., "black")`，不重跑 v4/v5，不改属性。
- 新用户走现有 `seedMerchantStatesForUser`（Open 为真则 Unlocked）。

### 3.2 收购

`SellItemForUserWithKey` 里实例货、堆叠货两处种类校验：黑市跳过，任意种类可卖。

价格：`min(0.28, 0.20+rep*0.002)`，专精公式不变。好感加在黑市自己身上。FIR 与商店货都能卖。

### 3.3 货架（卖给玩家）

每 6 小时一个自然周期（UTC 对齐）。按用户 `userID ^ cycleStart` 确定性抽 `24` 格：

- 池：全部目录（`catalog.ListAll`），`Price<=0` 或权重 0 的跳过
- 战利品权重 = `DropWeight`；弹药按 N 级映射 40/12/4/2/1；其它装备按价格带映射
- 售价 = `2 * buyMultiplier(rep) * 标价`
- 库存写在 `user_black_market_offers`，买完本轮消失；不要求专精好感门槛

### 3.4 前端

商人页黑市可点进。货架显示库存和下次刷新；收购列表展示仓库里任意货物。

### 3.5 验证

- 螺丝、Salewa、LEDX 都能卖给黑市；武器商人仍拒收螺丝。
- 同一件卖给黑市的钱少于卖给对应专精商人。
- 货架约 24 格，售价约为专精买入价的两倍（同好感）；买完库存下降；6 小时后重抽。

## 4. B：第二张图

### 4.1 拓扑

新 `map_id = factory_woods`，名称「林缘厂房」。6～7 节点，少于城区。`LayoutColumns/Rows` 可仍 3×3，空格不放节点，前端画布已按坐标排。

| 节点 | 标签 | 默认敌人 / 遭遇 | 容器 |
|---|---|---|---|
| 林道 | outdoor far | `template_boss_shturman` / role=boss，chance 20～30 | ground_cache、夹克（低权） |
| 伐木场 | outdoor | guard | 木箱、工具 |
| 厂房车间 | indoor industrial，建议出生点 | guard/elite | 工具箱、机箱 |
| 车间办公室 | indoor high_value | `template_boss_killa` / role=boss，chance 30 左右 | 文件柜、保险箱 |
| 油料棚 | fuel | guard | fuel_stash |
| 装卸坡 | cargo | patrol | 货箱 |
| 林间撤离点 | extraction far | extraction | 低价值 |

1～2 个撤离锚点。非 Boss 节点 `EncounterChance` 整体高于城区。边双向，MoveTime 与城区同量级。

室内/室外 Boss 用节点 `EnemyID` 钉死模板，不要只靠同一条 `Role=boss` 池去抽：池按角色合并，室内办公室可能抽到施图尔曼。

### 4.2 种子

- 新建 `seed_map_factory.go`（或同等独立函数），只 upsert `factory_woods`。
- `seedMap` 继续只全量替换 `city_ruins`。禁止对城区做 DELETE 后只插新图。
- `Seed()` 里 `seedMap` 之后调新图函数。
- 节点容器：零件/工具/燃料为主；夹克权重低于城区。
- 事件：全局巡逻/伏击/撤离事件会自动作用到新图，不必复制一份。另加 1～2 个厂房/林道节点绑定；钥匙门 0～1 扇（厂房铁门），钥匙出在本图夹克/文件柜。
- 合同：武器/机械链各 +2～3 条（探厂房、探林道、上交零件/电瓶）。医疗/服装链仍以城区为主。可选 1 条 `defeat_kind=boss`。

### 4.3 出发

探索页地图下拉要列出 `city_ruins` 与 `factory_woods`（`GET /maps` 有两行即可，前端已按列表渲染）。购物清单文案里的目标节点名要能解析新图。

快照按所选地图构建。旧城区 Session 不换图。

## 5. C：Boss（跟第二张图一起交）

### 5.1 出现

城区 `encounterPools()` **不改**。

新图必须写进同一个 `encounterPools()`（`seedEvents` 全表重建）：

```
factory_woods + role boss
  template_boss_killa     权重大（室内事件覆盖用）
  template_boss_shturman  权重大（室外事件覆盖用）
  可各挂一条 elite 低权重，避免池子只有一条
```

节点：

- 车间办公室：`EnemyID=template_boss_killa`，`EncounterRole=boss`，`EncounterChance` 约 30
- 林道：`EnemyID=template_boss_shturman`，`EncounterRole=boss`，`EncounterChance` 约 20～30

`resolveNodeEncounter`：未发生事件强制遭遇时，有 `EnemyID` 就用节点敌人，再掷 `EncounterChance`。不要把 chance 设成 100，否则每趟必打。

`enemygen` 已处理 Boss 固定枪甲和名称。生成时带上节点 `ValueTier`，保持现有确定性。

`nodeRisk` 增加 `boss` → 高于 elite（建议 6）。不改战斗公式。

### 5.2 掉落

击倒后现有逻辑搜 `BackpackContainerID`（精英包）。本版补：

- 生成器把模板 `BossLootItems` 拷进 `engine.Enemy`（新字段 `omitempty`，旧快照缺省空切片，schema 仍 v9）。
- 若击倒且 `Kind=boss` 且该切片非空，在背包搜索之外按权重再滚 1 件 FIR 进携行（容量不足则放弃并写报告）。
- 种子给基拉/施图尔曼各填 2～4 个高价值 ID（如 graphics_card、ledx 低权、weapon_parts、military 件），不要每趟必出 LEDX。

旧城区 v18 局没有 Boss，多出来的掉落分支不会改它们的结算。不必为此升 v19。

`BossAmmoDrop` 若仍未接，本版可以继续不管（击倒已有弹药缴获）。

### 5.3 合同

`defeat_kind` + `kind=boss` 即可，不必新 objective 类型。进度仍只在 PMC 成功撤离后、快照冻结合同上累加。

## 6. 文件边界

| 块 | 落点 |
|---|---|
| 黑市 | `seed_merchants.go`、`merchant.go` 出售/目录、`userdata_upgrade.go` v6、前端商人页无需大改 |

| Boss | `seed_events.go` 遭遇池、`seed_map_factory` 节点 EnemyID/role/chance、`seed_enemy_templates` 填 `BossLootItems`、`enemygen` 拷到 `engine.Enemy`、`run_simulation_detail` 击倒额外掉落、`route.go` `nodeRisk` |
| 出发 | 前端已读 `/maps`；若有写死 `city_ruins` 的文案再改 |

迁移：黑市解锁用数据适配版本即可，不一定要新 SQL。新图全是种子。`BossLootItems` 列已在模板表里，不必 0025。

生产：`migrate` + `seed`。不要同步每个玩家的合同进度。

## 7. 风险

| 风险 | 处理 |
|---|---|
| 黑市把专精商人架空 | 收购价明显更低；高价货仍建议去医疗/武器 |
| Boss 每局必打 | EncounterChance 远小于 100；节点有 EnemyID 仍要掷概率 |
| 室内抽到林区 Boss | 节点钉 `EnemyID`，不要只靠混合 boss 池 |
| 潜行路线钻 Boss 房 | `nodeRisk("boss")` 必须高于 elite |
| Boss 掉落毁稀有度 | `BossLootItems` 低权重，LEDX 不要 100% |
| 新图种子误删城区 | `seedMap` 继续只动 `city_ruins`；新函数只动 `factory_woods` |
| `seedEvents` 冲掉新池 | boss 池写进 `encounterPools()`，不要旁路插入 |
| 旧 Session | 快照带自己的 mapId 与敌人，不读新遭遇池 |

## 8. 验证

A：螺丝可卖黑市、不可卖武器商人；LEDX 可卖黑市；黑市卖价更低；v6 后旧号能看见黑市。

B：`/maps` 两张图；选工厂出发快照节点为 `factory_woods_*`；城区合同探点不因工厂局完成。

C：城区 100 局遭遇池抽不到基拉；工厂办公室有概率出「【BOSS】铁腕·基拉」，林道有概率出施图尔曼；未掷中则安全通过；击倒后报告里有背包外的 Boss 件或明确「容量放弃」；`defeat_kind=boss` 合同只在击倒后 +1。
